# Python Basics

A collection of beginner-friendly Python programs covering core concepts: data structures, recursion, loops, and generators. Each file is standalone and can be run directly.

## Files

| File | What it covers |
|------|----------------|
| `list.py` | Add, remove, slicing, sorting, looping, list comprehension |
| `dictionary.py` | Add, update, delete, looping, dict comprehension, word counter |
| `factorial.py` | Factorial using loop, recursion, and `math.factorial` |
| `fibonacci.py` | Fibonacci series using loop, recursion, and generator |
| `multiplication.py` | Multiplication table and full 10x10 grid |

## Requirements

- Python 3.8 or higher
- No external libraries needed

## How to Run

```bash
git clone <https://github.com/mohit-dotasara/PYTHONBASICS--25BCON2801-/new/main?filename=README.md>
cd < PYTHONBASICS--25BCON2801->

python list.py
python dictionary.py
python factorial.py
python fibonacci.py
python multiplication.py
```

`factorial.py`, `fibonacci.py` and `multiplication.py` ask for input in the terminal.
