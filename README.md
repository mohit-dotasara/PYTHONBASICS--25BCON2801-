# Python Basics

A collection of beginner-friendly Python programs covering core concepts: data structures, recursion, loops, and generators. Each file is standalone and can be run directly. This is Below

## Files

| File | What it covers |
|------|----------------|
| `list.py` | Add, remove, slicing, sorting, looping, list comprehension |
| `dictionary.py` | Add, update, delete, looping, dict comprehension, word counter |
| `factorial.py` | Factorial using loop, recursion, and `math.factorial` |
| `fibonacci.py` | Fibonacci series using loop, recursion, and generator |
| `multiplication.py` | Multiplication table and full 10x10 grid |

## Session 5 Programs
